# Smart-Ingredient-Planner-
A Unit Final project for Modern Technology online course. The "Smart" Ingredient Planner is AI driven program that The idea is for interactive, data-driven website application that generates personalized recipes based on ingredient that users already own, but doesn't know a use for it. This app will allow to maximizes the utility of their current grocery inventory by offering substitution and tracking ingredient freshness to minimize overall food waste. 

## Technology Stack 
- **Frontend**: React & TypeScript
- **Backend**: Node.js & Express
- **AI Integration**: Copilot, OpenAI, or Gemini
- **Database**: MongoDB
- **Deployment**: Docker & Google Cloud
